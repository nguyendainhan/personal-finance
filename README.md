# Personal Finance 💰

Hệ thống quản lý tài chính cá nhân Full-stack giúp theo dõi thu/chi, quản lý ví tiền, thống kê theo tháng và thiết lập hạn mức ngân sách.

## 🛠 Công nghệ sử dụng
* **Frontend:** React (Vite), Tailwind CSS v4, Recharts, SheetJS (xlsx)
* **Backend:** Node.js, Express, MySQL, CORS
* **Database:** MySQL (Bao gồm Trigger tự động đối soát tiền)

---

### 1. Yêu cầu hệ thống (Prerequisites)
